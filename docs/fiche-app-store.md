# Fiche App Store — Décide pour moi

Tout est prêt à copier-coller dans App Store Connect. Chaque champ respecte
sa limite (vérifiée par script) : nom et sous-titre 30, mots-clés 100,
texte promotionnel 170, description 4000.

Le texte promotionnel n'est pas indexé par la recherche et se modifie sans
nouvelle version : c'est le champ à faire vivre. Le champ mots-clés, lui,
est indexé mais invisible — virgules sans espaces, et jamais un mot déjà
présent dans le nom ou le sous-titre, ce serait de la place perdue.

## Choix faits, et pourquoi

- **Le nom reste la marque seule.** « Décide pour moi » est une requête en
  soi ; le sous-titre porte « tirage au sort personnalisable », le champ
  mots-clés porte « roue ». Chaque emplacement indexé travaille sans
  doublon.
- **Des mots-clés anglais sur la fiche française** (wheel, spinner) : la
  recherche française reçoit beaucoup de requêtes en anglais sur ce
  concept, autant les capter.
- **« prof » dans les mots-clés FR** : l'ordre de passage est le
  différenciateur revendiqué, autant être trouvable par ce public.
- **Aucun prix dans la description** : les prix varient selon les pays et
  changent sans nouvelle version ; la description mentionne l'essai de
  3 jours et la transparence, les chiffres restent au paywall.
- **Pas de superlatifs invérifiables** ni de mention d'autres marques :
  deux motifs de rejet évités.
